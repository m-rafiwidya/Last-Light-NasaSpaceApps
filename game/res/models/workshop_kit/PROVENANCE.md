# Workshop kit provenance

Every part here is an original design, generated by script in Blender 5.2 from the numbers in
`tools/blender/WORKSHOP_KIT.md`. No borrowed or AI-generated meshes, no textures, no third-party
assets. Sources: `tools/blender/parts/workshop/<asset>.blend`.

| Part | Generator |
|---|---|
| `ws_wall_panel`, `ws_wall_window`, `ws_wall_bay_door` (with `bay_door`), `ws_corner`, `ws_floor_tile`, `ws_plinth`, `ws_roof_tile`, `ws_partition_solid`, `ws_partition_door` (with `personnel_door`), `ws_partition_window`, `ws_work_lamp`, `ws_door_panel` | `tools/blender/scripts/workshop/make_shell.py` |
| `ws_pad` (with `charge_probe`), `ws_charger`, `ws_cable_cover` | `make_pad.py` |
| `ws_rack` | `make_rack.py` |
| `ws_console` (with `console_screen`) | `make_console.py` |
| `ws_marker_post`, `ws_sign_route`, `ws_sign_base`, `ws_sign_heritage`, `ws_floor_chevron`, `ws_floor_stripe`, `ws_door_sign` | `make_markers.py` |
| `ws_layout` (empties only) | `make_layout.py` |

Scale and collision were reviewed by the generators' own checks (dimensions, clearances, the
rover's path and the player's reach); see the scripts' `WORKSHOP_KIT ...` report lines.
