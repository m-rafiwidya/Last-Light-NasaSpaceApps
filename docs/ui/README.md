# docs/ui

UI design reference for LAST LIGHT.

- `UI_SPEC.md`: shared colours, fonts, components, motion, and what each screen contains. Start here.
- `PROMPTS.md`: the order to implement the screens with Claude Code, one prompt per step.
- `boards/`: the designs as HTML (1600 × 900). Exact sizes, spacing and timings live here.
- `screenshots/`: one image per board for a quick visual check.
- `assets/astronaut-logo.svg`: the logo. `assets/fonts/`: Michroma, Exo 2, IBM Plex Mono (SIL Open Font License, licences included).

Text on the boards is placeholder. Story names and lines come from `game/docs/STORY_SCRIPT.md`.
